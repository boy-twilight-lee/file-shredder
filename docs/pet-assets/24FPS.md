# 默认桌宠 24fps 图集

当前运行时素材为 `src/assets/pet-templates/default-pet-atlas.webp`，布局、动作帧号和时长统一从同目录 `default-pet-atlas.json` 读取。

| 动作 | 时长 | 帧数 |
| --- | --- | --- |
| 待机手部摆动 | 2 秒 | 48 |
| 向右移动 | 0.75 秒 | 18 |
| 向左移动 | 0.75 秒 | 18 |
| 清理 | 1 秒 | 24 |
| 完成 | 1 秒 | 24 |
| 失败 | 1 秒 | 24 |
| 等待确认 | 1 秒 | 24 |
| 思考 | 1 秒 | 24 |

204 个动态帧，加 8 个静态方向姿势，共 212 帧。停步保持姿势是静态停留，不强行添加重复帧。每个动态帧停留 1000/24 毫秒，播放由 Chromium 合成器推进。左右转向保留脚步相位，原生拖拽和松手缓冲保持原有策略。

生成方法：使用已经生成的高清关键姿势作为纹理，通过局部连续位移场渲染肢体的中间位置。每帧只从一张完整姿势采样，不交叉淡化、不叠加两张人物、不使用光流。此方式是局部图像变形动画，未生成独立的 3D 模型，也不是让图像模型独立绘制 212 张图片。动作幅度刻意保持较小，避免身体跳动和大幅变形。

当前单格为 512×512，图集 15×15、7680×7680，无损 WebP 约 6.24MB。帧数增加后将原 640 像素画布缩至 512 像素，支持当前 400 CSS 像素的最大设置；高 DPI 下不应理解为无限分辨率。整图解码约占 225MiB RGBA 内存，单图集方案的内存开销明显高于少帧版本。

定位规则：图片宽高为容器宽高的 `columns` / `rows` 倍；帧横向位移为 `-(frame % columns) / columns × 100%`，纵向同理。百分比以整张图片为基准，缩放不改帧号或重新播放动画。样式不再硬编码图集行列数。普通操作菜单继续播放待机手势，确认/进度/结果仍使用专属动作。

重建当前素材：`python scripts/prepare_pet_24fps.py`。依赖 NumPy、Pillow、OpenCV。输入为冻结的 `key-atlas.webp`（40 个高清关键帧，7 列，每格 640 像素），保留原始来源以便复现。

验证：

- `python scripts/check_pet_frames.py` 检查各动作 24fps、每帧图像哈希唯一、裤腰中心像素固定、无越界裁切。
- `python scripts/smoke_pet_atlas.py` 检查实际 Electron 解码、50/73/125.5/200/317/400 像素下的帧坐标、缩放不重播、转向相位、停止缓冲、原生拖拽区域、自定义图片不参与动画。
- TypeScript 检查和生产构建通过。物理鼠标拖窗延迟未实测。

`idle-24fps.webp`、`right-24fps.webp` 等为可独立播放的动画预览，图集才是运行时素材。
