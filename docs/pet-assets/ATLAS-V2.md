# 默认桌宠统一图集

本文记录早期关键帧版本，当前运行时已切换为 [24fps 图集](24FPS.md)。以下帧号、尺寸和节奏仅用于历史关键帧素材说明。

以 `sources-v2/reference.png` 为参考，重新生成黄色小河马、橙色短裤、头顶橘子和绿叶形象。

运行时素材：`src/assets/pet-templates/default-pet-atlas.webp`。无损透明 WebP，3840×3840，6×6 网格，每格 640×640，共 36 个有效帧。生成源图每格约 627 像素，按原始像素放入统一画布，没有插值补帧或重影混合。

| 帧编号（从 0 开始） | 用途 |
| --- | --- |
| 0–3 | 待机、微笑、眨眼 |
| 4–7 | 向右移动，原地小步抬脚 |
| 8–11 | 清理中，双手搓动 |
| 12–13 | 完成，点赞微笑 |
| 14–15 | 失败，失落和叹气 |
| 16–17 | 等待确认 |
| 18–19 | 查看、思考 |
| 20–23 | 上、下、右上、右下 |
| 24–27 | 向左移动，右向帧镜像 |
| 28–31 | 方向表情镜像，其中 30–31 用于左上、左下 |
| 32–35 | 待机抬手、弯臂、挥手；按逆序放下手臂 |

以橙色裤腰和臀部中心做平移对齐，不按举手、抬脚后的外接框缩放。源帧腰线固定 y=470，水平锚点为 x=320±0.5。这个数值描述检测锚点；生成画面仍有小幅表情和身体轮廓变化。无整只角色弹跳或位置补间。

渲染使用常驻图片节点和同一个 `src`，Web Animations API 在 Chromium 合成器上离散切帧。原生 Electron 拖动逻辑保持；左右拖动使用四个脚部关键帧，反向时保留脚步相位。自定义上传图片仍走独立原图分支。

方向状态仅来自原生移动事件，移除了 `screenX/screenY` 逐帧采样覆盖和 180ms 清空逻辑。方向加入 34° 滞回区间，相邻方向持续 70ms 才接受，避免反复跨过扇区边界重播动画。松开后缓冲 160ms，再完成当前脚步并收脚停留 650ms，随后恢复当前业务动作；事件静默 320ms 时同样进入收脚流程。再次移动立即打断停留。待机挥手为 8.25 秒周期，眨眼 130ms，挥手关键帧 170–220ms，休息帧 550–1600ms，避免所有帧等速停留。

重建：`python scripts/prepare_pet_atlas_v2.py`，需要 Pillow 和 NumPy。源图先生成洋红底，再程序去底并清理边缘；完整源图保存在 `sources-v2`。

验证：类型检查、生产构建、37 项测试通过。`python scripts/smoke_pet_atlas.py` 在 Electron 中验证 400 CSS 像素尺寸、图集解码、方向帧、左右脚部动画、状态切换保持相同节点和地址、原生 drag 区域、自定义图片无动画，并覆盖方向噪声/短暂空事件不重播、反向保留相位、延迟恢复、新拖动打断停留及待机手势序列。`atlas-v2-400px.png` 为实际渲染截图（像素尺寸受系统缩放影响）。此检查通过模拟原生事件流验证状态逻辑，没有模拟物理鼠标拖窗，未测量真实拖动延迟。
