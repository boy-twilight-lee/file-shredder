# 默认桌宠高清素材

默认人物以用户提供的黄色桌宠和本次确认的高清重绘形象为参考，保留橙色口鼻、小角、头顶凸起、黄色衣服、绿色肩带和白色动物脸挎包。

- 内置 image_gen 工具分七组生成 28 个关键姿势，原始输出存于 `sources/`。
- 每个源文件为 1254×1254、2×2 排列。采用洋红背景，避免白色背包与透明底预览棋盘格混淆。
- Python 使用色键去背景并去除边缘溢色，保持白色和黑色部件；所有姿势采用相同缩放，并以脚底和双脚中心定位，不以变化的手臂或头部外框居中。
- 只播放原地眨眼、轻微抬手和表情动作；成功采用原地举手，拖拽采用固定朝向，不播放跑步或跳跃。每格仅保留真实姿势，不混合、变形或插值生成中间帧，避免重影。
- 图集统一为 16 格，重复真实帧控制停留时长。失败播放后停留，方向图集用于固定姿势。素材生成的其他姿势保留在源文件中，运行时不全部采用。
- 发布素材为 640×640 单帧、2560×2560 的 4×4 WebP 图集。640px 是输出画布尺寸，源图每格约 627px，不能理解为无限分辨率。
- 运行时按状态加载独立纹理，以 CSS 离散 transform 动画播放。原生拖拽保留；渲染层只读屏幕位置补充方向反馈，不调用窗口定位接口接管拖拽。
- 自定义上传图片始终使用原始图片，不裁剪图集、不镜像、不套用默认动画。

重建命令：

```text
python scripts/prepare_pet_atlas.py docs/pet-assets/sources src/assets/pet-templates
```

素材构建依赖：Pillow、NumPy、Python 3；应用运行不依赖这些 Python 库。

## 生成提示词集

使用内置 image_gen，参考先前高清形象及原图比例。共同提示词要求：2×2 等大网格、完整人物、同一角色和服装、统一比例和脚底位置、高清毛绒细节、完整白色挎包、纯洋红 `#FF00FF` 背景、无网格文字和地面阴影。初次请求 2048×2048，工具实际返回 1254×1254。

各源文件的姿势提示：

| 文件          | 四个关键姿势                                             |
| ------------- | -------------------------------------------------------- |
| idle.png      | 正面中性、轻微抬头呼吸、闭眼眨眼、睁眼微笑               |
| run-a.png     | 向右跑步周期前半段：接触地面、重心下沉、腿经过、身体上升 |
| run-b.png     | 向右跑步周期后半段：交替支撑、膝盖弯曲、腿前伸、双腿经过 |
| working.png   | 正面双手在胸前轻轻清理，依次居中、左移、抬起、右移       |
| reactions.png | 举手庆祝、轻跳庆祝、失落睁眼、低头半闭眼                 |
| social.png    | 合手等待、倾头等待、托腮查看、反向倾头查看               |
| look.png      | 仰视、俯视、右上看、右下看                               |

图像生成后仅进行去背景、对齐、缩放和真实帧重复，不使用光流、混合帧或渐变叠加。
