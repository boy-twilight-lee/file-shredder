# 桌宠独立 WebP 动作

当前实现使用 `src/assets/pet-templates/motions/` 下的透明 WebP。旧图集与 24fps 文档保留为历史记录，不再由角色组件加载。

| 状态 | 画面 | 播放方式 |
| --- | --- | --- |
| 默认 | 微笑、眨眼，身体保持不动 | 5 秒循环，闭眼 140ms |
| 操作菜单 | 手指向左侧 action 气泡 | 固定图片 |
| 移动 | 左右小步移动；忽略上下与斜向姿势 | 左右独立 WebP，各 720ms 循环 |
| 等待确认 | 微微歪头、双手自然交叠 | 固定图片 |
| loading | 双手扶着迷你碎纸机，纸张送入、纸屑在收集窗内落下 | 5 秒循环 |
| 成功 | 睁眼微笑、笑眯眼，保持明显的大拇指手势 | 5 秒表情循环 |
| 失败 | 失落、闭眼、张嘴叹气、恢复 | 5 秒表情循环 |
| 取消 / 设置 / 记录 | 查看姿势 | 固定图片 |

## working 动作修订

移除对手掌、手臂和躯干的局部位移场、OpenCV remap 和拉伸补帧。人物与机器来自一张完整生成姿势，每帧人物像素保持一致。只有纸张图层平移送入和纸屑在收集窗内落下，进纸口负责遮挡纸张，循环末尾回到空机状态。

碎纸机采用奶油白圆润顶盖、深青色机身、金属进纸口、状态指示灯和内嵌收集窗。按 24fps 采样 120 帧；WebP 无损编码会合并相同的停留帧，当前编码后为 95 帧，总时长精确为 5000ms。640×640，约 0.96MiB；当前 11 个状态素材合计约 3.12MiB。它是静态角色与运动纸张的分层合成动画，不是视频生成或三维骨骼动画。

左右步行使用 docs 原有的四张完整绘制姿势，每帧 180ms，按源图统一的腰线与臀部中心锚点对齐，左向由右向镜像。移除固定上半身与不同下半身的硬拼接，整张姿势完整播放，避免腰部图层错位。没有拉伸、光流或插值变形。构建脚本逐像素检查编码后的步行帧与完整源姿势一致。成功、失败仅替换绘制的眼睛和嘴部区域，保留头部轮廓、手臂与身体；叹气使用原有呼气表情。

角色组件保留同一个 img，解码完成后再切换地址，旧请求不能覆盖新状态。尺寸变化和进度更新不会重设同状态的 src。原生拖动区域保留，只有有效水平位移改变左右朝向；垂直拖动延续已有朝向。松手后 120ms 进入静态收脚姿势，再停留 180ms 恢复当前页面；原生事件静默 320ms 同样收脚。成功/失败不再叠加循环光圈。自定义图片使用原独立分支。

## 素材与重建

- 原始角色关键姿势：`key-atlas.webp`。
- 新指向姿势：`sources-v2/actions-point.png`。
- 新工作姿势：`sources-v2/working-shredder-refined.png`。
- 新等待姿势：`sources-v2/waiting-refined.png`。
- 生成方式：内置 image_gen；采用洋红底，经现有去底流程转为透明图片。
- 提示词要点：保持黄色小河马、橙色短裤、头顶橘子与绿叶和原有比例；action 伸出食指指向左侧；working 双手自然扶住奶油白与深青色迷你碎纸机，目光轻垂，机器有金属进纸口、指示灯和收集窗，源图不含纸张；waiting 轻微歪头、目光期待、双手放松交叠；背景均为纯 #FF00FF。
- 重建：`python scripts/prepare_pet_webp.py`，依赖 Pillow、NumPy。
- 素材检查报告：`webp-validation.json`；姿势预览：`webp-poses-preview.jpg`。
- Electron 回归：先执行 `npm run build:app`，再执行 `python scripts/smoke_pet_webp.py`。

当前运行时只保留左右移动和左右收脚资源。旧八方向运行时图集、图集生成和旧回归脚本已移除；`key-atlas.webp` 是仍在使用的原始姿势来源，历史文档仅作溯源。去底公共函数集中在 `scripts/pet_image_utils.py`。

回归脚本在隔离的隐藏 Electron 窗口内模拟状态和原生方向事件，不执行真实文件粉碎，也不模拟物理鼠标拖窗。
