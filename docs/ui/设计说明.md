## 页面清单

> **v6 布局约定（2026-09-23）**：02–09 页采用「单一大容器 + 内部分区」的 Ant Design 后台形态——每页正文只有 **1 个主面板**（白底 + 圆角 12 + 描边 `#E0E6EB`），内部逻辑分区用 1px 分割线 `#F2F5FA` 分隔；统计指标一律为**无边框横排数字行**（彩色圆盘图标 + 灰标签 + 加粗数值），不再使用独立统计卡。01 拖拽导入页保持不套卡片的原样。

## 图表与插画

- **环形进度 / 完成率环（重要）**：用 ELLIPSE 的 `arcData` 甜甜圈弧（`innerRadius` ≈ 0.79 + `startingAngle` / `endingAngle`，从 -1.5708（12 点方向）顺时针累加），进度弧叠在底环之上、**弧层必须在中心文字下方**（先插弧、后插文字，或用 `M` 把弧移到低 index）。**不要用** SVG `circle + stroke-dasharray`（本渲染器弧会破碎）或 ELLIPSE stroke + rotation（弧错位）。中心数字用全宽 frame + `counterAxisAlignItems: CENTER` 居中。
- 分段环配色：成功 `#26A555` / 跳过 `#FFA126` / 失败 `#FF4C26`；类型构成环按文档/表格/图片/音频/程序分色。
- 柱状图：SVG `rect`（底线用高度 1.5 的 rect，不要零高度轴线）。
- 统计卡图标：彩色实心圆盘挖空字形，不另叠背景。
- 插画（拖拽框 / 成功盾牌 / 失败警示）：几何形 + 圆点装饰，主色 `#0065FF` / 危险 `#FF4C26` 两套。
- 拖拽框底：`GRADIENT_LINEAR` 浅蓝 `#E3F0FF` → 近白 `#F8FAFF`，避免与页面底色 `#F5F7FA` 重合。

## 文件类型图标

「主流桌面客户端」风格：彩色文档形底 + 白色折角 + 白色内容条 / 字形，按类型着色
（文档蓝 / 表格绿 / 图片橙 / 音频紫 / 程序青 / 密钥红 ……）。**不要退回 vscode-icons 扁平风**。

画布上有一套 **14 枚标准图标集**（节点 `3:518` 面板，32×32 圆角底 + 白色字形 SVG）：文件夹 / 文档 / 表格 / 数据 / 演示 / PDF / 文本 / 代码 / 图片 / 视频 / 音频 / 压缩包 / 程序 / 密钥。02 页目标表与 04 页类型环均引用此风格，新增文件类型先从这套里取。

## 品牌图标流水线

```bash
python docs/ui/brand/build-icon.py
```

- 输入：`brand/logo-src.jpg`（用户提供的品牌插画，**只读**）+ `brand/build-icon.py`（含去水印 / 裁切 / 圆角蒙版的完整参数）。
- 输出：`brand/logo.png`（512）、`brand/icon-16…256.png`、`brand/app-icon.ico`，并**同步覆盖** `src/assets/app-icon.png|ico`。
- `src/assets/app-icon.*` 是 `electron/app/paths.ts` 与 electron-builder（`package.json` → `win.icon` / `nsis.installerIcon`）读取的文件，不要手工替换。
- 脚本通过向上查找 `package.json` 定位项目根，可以放在任意层深；**不要手工改产出的图**。
